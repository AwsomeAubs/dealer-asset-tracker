# Hyundai Dealer Brand Asset Tracker

Live tracker for TV screens, A0 snapper frames, N-Line displays and billboards across HASA dealerships, for the "Progress. Driven by Hyundai" KV rollout.

- **View:** open the GitHub Pages link. Anyone with the link can view.
- **Edit:** click **🔑 Connect to edit** and paste a GitHub fine-grained token with *Contents: read and write* on this repo only. The key is stored in that browser only.
- **Data:** `data/state.json` (every save is a commit, so the history is the audit trail).
- **Proofs:** `proofs/<dealer>/` (photos are resized before upload).
- **Excel:** Download Excel builds a workbook with dropdowns and a regional summary.
